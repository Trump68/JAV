# Project brief

## Scope

Репозиторий **JAV** — набор Python-скриптов для работы со страницами Supjav: извлечение URL потоков (m3u8, mp4, iframe), опциональная загрузка через yt-dlp/браузер, пакетная обработка списков актрис, локальная нарезка видео через ffmpeg.

## Core goals

- Надёжно открывать страницу плеера (переключение вкладки сервера при необходимости) и находить рабочие URL стрима.
- Поддерживать headless и визуальный режим; при антиботе отдавать предпочтение Chrome и `--visual`.
- Учитывать изменения вёрстки/логики целевого сайта — селекторы и фильтры могут требовать правок.

## Out of scope

- Обход правовых ограничений или нарушение условий использования сайта — инструменты предполагают ответственное использование (см. README).
